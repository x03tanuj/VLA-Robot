# Contributing to VLA Robot

Thank you for your interest in contributing! This document covers a few simple ways to help.

- Issues: open issues for bugs, feature requests, or documentation fixes. Use clear titles and reproduction steps.
- Branches: create topic branches from `main` with the pattern `feat/your-feature` or `fix/issue-123`.
- Pull requests: keep PRs small, describe the change, and reference related issues.
- Code style: follow existing code patterns. Run linters and tests before submitting.
- Communication: add screenshots or a short GIF demonstrating UI changes.

If you want me to add a CONTRIBUTING checklist with pre-commit hooks and a template, tell me and I'll add them.
